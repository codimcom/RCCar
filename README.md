# RCcar

Проект радиоуправляемой машинки с управлением со смартфона через Bluetooth. Машинка под управлением Ардуино может плавно менять скорость движения и угол поворота колес.

## Структура

- `app/` — приложение Android на Kotlin.
- `arduino/RCcar/RCcar.ino` — скетч Arduino для управления машинкой по Bluetooth.

## Состояние проекта

Приложение Android ищет сопряжённый Bluetooth-модуль с именем `HC-06` и отправляет однобайтовые команды. Скетч Arduino принимает команды через `SoftwareSerial` на пинах 2 и 3 и декодирует их в значения поворота и скорости от −5 до 5.

Для Android откройте корень репозитория в Android Studio и соберите модуль `app`. Для Arduino откройте `arduino/RCcar/RCcar.ino` в Arduino IDE и выберите используемую плату.
